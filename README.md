# musaydkhan.github.io

Personal site of Musayd. A static page (HTML, CSS, a little JavaScript, Three.js from cdnjs). No backend, logins or tracking.

## Edit
- Open `index.html` on GitHub, click the pencil icon, change the text between the `<!-- EDIT: ... -->` comments, then commit. The site updates in about a minute.
- Keep your GitHub account protected with 2FA or a passkey. Never put tokens or passwords in this repo.
