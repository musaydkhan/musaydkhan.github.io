# musaydkhan.github.io

Personal site of Musayd. Static pages built by GitHub Pages (Jekyll). No backend, logins or tracking.

## Edit the home page
Open `index.html` on GitHub, click the pencil icon, change the text, and commit. Do not remove the first lines of the file (the two `---` lines at the top).

## Publish a writing
1. In the repo choose Add file, then Create new file.
2. Name it `_posts/YYYY-MM-DD-short-title.md` (for example `_posts/2026-11-20-my-first-post.md`). Typing `_posts/` creates the folder.
3. Paste the contents of `writing-template.md`, edit the title and description, and write the post in Markdown.
4. Commit. The post appears under /writings/ in a minute or two. The Writings link on the home page shows up automatically once the first post exists.

The date comes from the file name and must be today or earlier (Dhaka time), or the post stays hidden.

Keep your GitHub account protected with 2FA or a passkey. Never put tokens or passwords in this repo.
